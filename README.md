# Hi, I'm Oleksandr 👋

I build internal software for engineering teams. At **RECARO Aircraft
Seating** I develop the tools of the test laboratories — from requirements to
installed, documented tools that engineers use every day: test-data processing,
report automation and replacements for fragile Excel workflows.

I work **AI-first**: I define requirements, architecture and acceptance
criteria, coding agents implement, and automated tests and reviews keep the
result reliable.

I hold a Bachelor's degree recognised in Germany and now study **Mathematics
at the University of Stuttgart**. Where I'm heading: applied AI and machine
learning.

Outside of work I build things end to end — I write them, deploy them, and run
the servers they live on.

**Portfolio:** [**izotov.dev**](https://izotov.dev) 🌐
